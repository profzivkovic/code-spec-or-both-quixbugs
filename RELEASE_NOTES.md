# v1.0.0

Initial public reproducibility release for the manuscript:

**Code, Specification, or Both? Evaluating LLM-Generated Unit Tests on QuixBugs**

Contents include:

- exact CODE, SPEC, and BOTH prompts;
- all 99 generated pytest suites;
- raw Ollama responses and generation metadata;
- task preparation and validation artifacts;
- correct/buggy execution results and per-test outcomes;
- coverage and JUnit outputs;
- the final analysis script and derived tables/figures;
- the QuixBugs benchmark snapshot used by the experiment.

The public artifact may replace local absolute filesystem paths in runtime logs
with neutral placeholders. No generated tests, experimental outcomes, or
reported metrics are changed by that sanitization.
